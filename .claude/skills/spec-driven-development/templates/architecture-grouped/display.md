# 通知の表示 アーキテクチャ

## 1. 目的と範囲

通知の表示は、利用者の画面へ未読件数と通知の一覧を届ける。
通知の保管は、別の機能のくくりの対象である。

## 2. 構成要素

| 構成要素     | 種別   | 責務                                   | 実装spec           |
| ------------ | ------ | -------------------------------------- | ------------------ |
| 利用者       | 外部   | 画面を開いて未読件数と一覧を読む       | -                  |
| 通知バッジ   | 内部   | 未読件数をヘッダーに描画する           | notification-badge |
| 通知API      | 内部   | 未読件数を集計して返す                 | notification-api   |
| 通知一覧     | 内部   | 通知を新しい順に並べて画面に描画する   | notification-list  |
| 配信ワーカー | 他機能 | 保管した通知を宛先ごとに読み出して返す | -                  |

## 3. システム構成

画面の要素は通知APIを呼び、通知APIは配信ワーカーから通知を読み出す。

```mermaid
flowchart LR
  badge["通知バッジ"] --> api["通知API"]
  list["通知一覧"] --> api
  api --> worker["配信ワーカー"]
```

## 4. 外部インターフェース

| IF       | 方向 | 外部の要素 | 内部の要素 | 方式         | 認証              |
| -------- | ---- | ---------- | ---------- | ------------ | ----------------- |
| 通知表示 | 提供 | 利用者     | 通知バッジ | HTTPS の画面 | セッション Cookie |

利用者は、通知表示の辺で通知バッジにつながる。

```mermaid
flowchart LR
  subgraph システム境界
    badge["通知バッジ"]
  end
  ext_user["利用者"] -->|通知表示| badge
```

## 5. 機能

### 未読件数の表示

- 関与: 通知バッジ、通知API、配信ワーカー

未読件数の表示は、未読の有無でバッジの描画が分岐する。

```mermaid
sequenceDiagram
  participant badge as 通知バッジ
  participant api as 通知API
  participant worker as 配信ワーカー
  badge->>api: 未読件数の取得
  api->>worker: 未読通知の読み出し
  worker-->>api: 通知の一覧
  alt 未読がある
    api-->>badge: 件数
  else 未読がない
    api-->>badge: 空の応答
  end
```
