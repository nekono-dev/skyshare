# 通知バッジ 要件定義書

## 1. 目的

未読の通知件数をヘッダーに表示し、利用者が新着通知に気付けるようにする。

## 2. スコープ

### 2.1 対象

- 未読通知件数の取得と表示。
- 未読が0件のときの非表示。

### 2.2 対象外

- 通知本文の一覧表示。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: ヘッダーに未読通知の件数を数字で表示する。
- FR-2: 未読が0件のとき、バッジを表示しない。

## 5. 非機能要件

- NFR-1: ページ読み込み開始から1秒以内にバッジの表示を完了する。

## 6. 受け入れ条件

- AC-1 (FR-1): 未読が3件のとき、バッジに「3」が表示される。
- AC-2 (FR-2): 未読が0件のとき、バッジが描画されない。
- AC-3 (NFR-1): 通知取得の応答が500ミリ秒のとき、読み込み開始から1秒以内にバッジが表示される。
