# 実装計画

各タスクは、設計書の File Structure Plan の領域（領域 1〜9）ごとの「書き換えと確認」の単位。対象のファイルと許容リストの項目は、設計書の領域の節を参照する。

許容リスト（所有の項目を記録する一覧）は全 comments-* spec が共有するため、このタスク群は `(P)` を付けず、番号の順に直列で行う。各タスクの開始時に、許容リストを読み直す。
