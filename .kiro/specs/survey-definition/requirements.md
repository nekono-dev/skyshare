# Requirements Document

## Project Description (Input)

開発者（運営者）は、ログインした利用者の動向を探るために、期間を限ったアンケートを実施したい。現状、アンケートの質問・選択肢・期間を持つ仕組みはなく、質問をソフトウェアに組み込むと、質問を変えるたびにコードを変更することになり、フォークした開発者の環境にも不要なコードの影響が及ぶ。

アンケートの内容は、ソフトウェアに組み込まず、GitHub のリポジトリ変数 `SURVEY_CONFIG`（JSON）を元に CI がビルド時に静的ファイル `public/surveys/index.json` として生成し、配信する形にする。変数が未設定の環境（フォークを含む）ではファイルを作らず、アンケートは存在しない状態として何も起こらない。

この spec は、その設定の形式と検証、期間の判定、質問・選択肢・説明文の多言語（i18n）対応、変数から静的ファイルを生成するスクリプトと CI への組み込みを扱う。

### 合意済みの前提

- 質問は選択式（単一選択 `single` と複数選択 `multiple`）で、自由記述は持たない。選択肢に「回答しない」（`decline: true`）を指定でき、それを選んだ回答は完了として扱わない。
- 期間（`opensAt`〜`closesAt`）はオフセット付きの ISO 8601 とし、現在のアンケートは「`opensAt` ≤ 現在 < `closesAt`」で同時に最大 1 件。
- 利用者に見せる文言（タイトル・説明・質問・選択肢）は多言語とし、サポートする言語（現状は日本語・英語）すべての文言を必須にする。運営者が日本語を入力すれば、英語など他言語は施行ワークフローが同時に作成する。
- 変数が壊れた JSON のときは、サイレントに無効化せず、デプロイを失敗させる。
- 過去のアンケートは、回答データの削除が終わるまで変数に残す（削除期限の判定に使う）。
