# Requirements Document

## Introduction

動画の実体をskyshareのサーバーに通さずにBlueskyの動画サービスへ送り、変換後の動画を投稿に載せられるようにする。

## Boundary Context

- **In scope**:
  - 動画のアップロード用の認証トークンの発行。
  - ブラウザから動画サービスへの分割アップロードと変換の待機。
  - アップロードの失敗の分類と中断。
  - 投稿への動画の埋め込み。
- **Out of scope**:
  - 投稿フォームでの動画の選択と表示。
  - 対応PDS以外での動画の投稿と、字幕・GIF表示の指定。
  - ページの再読み込みをまたいだアップロードの再開。
- **Adjacent expectations**:
  - なし

## Requirements

### Requirement 1: アップロード用のトークン

**Objective:** As a 利用者, I want 動画サービスへ安全にアップロードする権限を得たい, so that サーバーを経由せずに動画を送れる

#### Acceptance Criteria

1. When トークンの発行が要求されたとき、the トークン発行 API shall 用途を動画のアップロードに限定し、有効期間を30分とした動画アップロード用の認証トークンを、PDS を対象・アップロードの操作を用途・30分後を期限として発行する
2. If 対応 PDS 以外のアカウントがトークンを要求したとき, then the トークン発行 API shall トークンを発行せず、対応外である旨のエラー（400）にし、動画を送信させない
3. The トークン発行 API shall トークンの応答をキャッシュさせず、トークンをサーバーとクライアントのログに出力しない

### Requirement 2: 分割アップロード

**Objective:** As a 利用者, I want 大きな動画も途中の失敗に強く送りたい, so that 通信が不安定でも投稿できる

#### Acceptance Criteria

1. The アップロード shall 動画をブラウザから動画サービスへ分割して直接送り、変換の完了を状態の問い合わせで待ち、完了後に動画の参照を返す
2. The アップロード shall 動画の実体のバイト列のうち、skyshare のサーバーへ送るバイト数を0にする
3. If パートの送信が通信エラー・500番台・429で失敗したとき, then the アップロード shall 待機を1秒・2秒・4秒と延ばして3回まで再試行し、400は再試行せず、4回続けて失敗すると通信エラーとする
4. When トークンの残りの有効期間が5分未満になったとき、the アップロード shall 次の送信の前にトークンを再発行する
5. When 送信の完了前に中断されたとき、the アップロード shall アップロードの破棄を要求する
6. When 送信の完了後に中断されたとき、the アップロード shall 破棄を要求せず、変換のジョブを放置する
7. If 変換の完了を20分待っても終わらないとき, then the アップロード shall 時間切れとして失敗にする

### Requirement 3: 失敗の分類

**Objective:** As a 利用者, I want 動画の失敗の原因が分かるようにしたい, so that 対処を判断できる

#### Acceptance Criteria

1. When 動画サービスがエラーを返したとき、the アップロード shall 失敗を、サイズ超過・縦横比・日次上限・権限・同時アップロード数・混雑・変換失敗・時間切れ・通信・対応外 PDS・不明に分類し、対応する利用者向けの文言に変換する

### Requirement 4: 投稿への埋め込み

**Objective:** As a 利用者, I want アップロードした動画を投稿に載せたい, so that 動画つきの投稿を作成できる

#### Acceptance Criteria

1. When 動画つきの投稿が作成されるとき、the 投稿の作成 shall アップロード済みの動画の参照・縦横比・代替テキストを動画の埋め込みとして投稿に載せる
2. If 動画と画像またはリンクカードが同時に指定されたとき, then the 投稿の作成 shall 400 で拒否する
3. When スレッドの複数の投稿に動画が指定されたとき、the 投稿の作成 shall それぞれの投稿に1本ずつ動画の埋め込みを載せる
