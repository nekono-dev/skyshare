# 投稿本文のリンク表示 要件定義書

## 1. 目的

タイムラインとentry詳細ページの投稿の本文で、メンション・ハッシュタグ・URLをリンクとして表示し、押すとBlueskyのプロフィール・ハッシュタグの検索・リンク先を開けるようにする。

## 2. スコープ

### 2.1 対象

- 投稿の本文の注釈からのリンクの区間の切り出し。
- タイムラインとentry詳細ページの本文のリンクの表示。
- 一覧APIの応答への本文の注釈の追加。

### 2.2 対象外

- 投稿フォームでの注釈の検出。
- 引用とリンクカードの埋め込みの表示。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: メンションはBlueskyのそのアカウントのプロフィール、ハッシュタグはBlueskyのそのタグの検索、URLはそのリンク先を開くリンクとして表示する。
- FR-2: リンクは新しいタブで開き、リンク以外の本文は元の文字のまま表示する。
- FR-3: 範囲が本文の外にはみ出す・他の注釈と重なる・文字の途中で切れる注釈は無視し、その範囲を文字のまま表示する。
- FR-4: URLの注釈のうち、リンク先がhttpとhttps以外の形式のものはリンクにせず、文字のまま表示する。
- FR-5: 一覧APIは、投稿ごとに本文の注釈を応答に含める。
- FR-6: 注釈の無い部分に書かれたURLも、リンクとして表示する。`https://`・`http://` を省略したURL（既知のトップレベルドメインで終わるもの）と、日本語の文字に空白なしで続くURLを含む。
- FR-7: entry詳細ページの説明文の中のURLも、FR-6と同じくリンクとして表示する。

## 5. 非機能要件

- NFR-1: JavaScriptの実行回数が0回のentry詳細ページでも、本文のリンクを表示する。
- NFR-2: 4バイトの絵文字を含む本文でも、リンクの範囲が1文字もずれないようにする。

## 6. 受け入れ条件

- AC-1 (FR-1): メンション・ハッシュタグ・URLを含む本文で、各リンクがプロフィール・ハッシュタグの検索・リンク先を指す。
- AC-2 (FR-2): リンクが新しいタブで開く指定を持ち、リンクの前後の文字が元の本文のまま表示される。
- AC-3 (FR-3): 範囲が本文の長さを超える注釈を持つ本文は、リンクを持たずに全文が表示される。
- AC-4 (FR-4): リンク先がjavascriptの形式の注釈は、リンクにならない。
- AC-5 (FR-5): 注釈を持つ投稿を一覧用に変換すると、投稿に注釈が含まれる。
- AC-6 (NFR-1): JavaScriptを無効にしたentry詳細ページで、本文のリンクが表示される。
- AC-7 (NFR-2): 絵文字の後ろにあるハッシュタグで、ハッシュタグの文字だけがリンクになる。
- AC-8 (FR-6): 注釈の無い本文の `example.com/a` と `見てexample.comです` の `example.com` が、`https://` を補ったリンク先のリンクになる。メールアドレスと `1.0.0` のような版の表記はリンクにならない。
- AC-9 (FR-7): entry詳細ページの説明文の `example.com` が、`https://example.com` を指すリンクになる。
