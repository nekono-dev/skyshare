# エディタのツールボックス 要件定義書

## 1. 目的

投稿本文の編集を補助する機能を、ボタン列とクリックで展開するパネルという1つの形で提供し、機能の追加を呼び出し側の変更だけで行えるようにする。

## 2. スコープ

### 2.1 対象

- ツールのボタン列の表示と折り返し。
- パネル型ツールのパネルの開閉と、即時実行型ツールの実行。
- キーボード操作と支援技術向けの属性。

### 2.2 対象外

- 個々のツールのパネルの中身と処理。
- 本文の選択範囲の取得と本文の編集。
- 既存の投稿フォームへの組み込み。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: 呼び出し側から渡されたツールの配列の順に、ラベルと任意のアイコンを持つボタンを横に並べる。
- FR-2: ボタン列がコンテナの幅を超える場合は、横スクロールにせず複数行に折り返す。
- FR-3: 無効を指定したツールのボタンは操作できない。
- FR-4: パネル型ツールのボタンを押すと、そのツールのパネルをボタンの直下に表示する。
- FR-5: 同時に開くパネルは1つとし、別のパネル型ツールのボタンを押すと開いていたパネルを閉じて新しいパネルを開く。
- FR-6: 開いているパネルのボタンをもう一度押すとパネルを閉じる。
- FR-7: パネルは、パネルの外側のクリック・Escキー・スクロール・ウィンドウのリサイズ・ツール側からの閉じる要求で閉じる。
- FR-8: 即時実行型ツールのボタンを押すと、パネルを開かずにそのツールの処理を実行する。
- FR-9: 押下状態を指定した即時実行型ツールのボタンは、トグルボタンとして押下状態を表示する。
- FR-10: 左右の矢印キーで、無効なボタンを飛ばしてツールの配列の順にフォーカスを移動する。
- FR-11: パネルを閉じたときは、そのパネルを開いたボタンへフォーカスを戻す。
- FR-12: ツールの追加と削除は、ツールの配列の組み立てだけで完結させ、ツールボックス自体の変更を必要としない。

## 5. 非機能要件

- NFR-1: パネルの位置の計算と最前面への描画は既存のフローティング表示の部品で行い、同じ処理の再実装を0件にする。

## 6. 受け入れ条件

- AC-1 (FR-1): 4件のツールを渡すと、配列の順に4つのボタンが表示される。
- AC-2 (FR-2): 8件のツールを幅360pxの画面で表示すると、ボタンが複数行に折り返し画面外にはみ出さない。
- AC-3 (FR-3): 無効を指定したツールのボタンを押しても、何も起きない。
- AC-4 (FR-4): パネル型ツールのボタンを押すと、ボタンの直下にパネルが表示される。
- AC-5 (FR-5): パネルを開いたまま別のパネル型ツールのボタンを押すと、開いていたパネルが閉じて新しいパネルが開く。
- AC-6 (FR-6): 開いているパネルのボタンをもう一度押すと、パネルが閉じる。
- AC-7 (FR-7): パネルの外側のクリックとEscキーで、パネルが閉じる。
- AC-8 (FR-8): 即時実行型ツールのボタンを押すと、パネルを表示せずに処理が実行される。
- AC-9 (FR-9): 押下状態のツールのボタンが、押下状態を示す属性を持つ。
- AC-10 (FR-10): 右矢印キーで、無効なボタンを飛ばして次のボタンにフォーカスが移る。
- AC-11 (FR-11): Escキーでパネルを閉じると、パネルを開いたボタンにフォーカスが戻る。
- AC-12 (FR-12): ツールの配列にツールを1件加えると、ツールボックスのコードを変えずにボタンが1つ増える。
- AC-13 (NFR-1): パネルが既存のフローティング表示の部品の中に描画される。
