# 投稿フォーム 要件定義書

## 1. 目的

1件の投稿と複数件のスレッドを同じ投稿フォームで作成し、スレッド全体を1回の操作で投稿できるようにする。

## 2. スコープ

### 2.1 対象

- 投稿フォームでのセグメント（スレッド内の1投稿）の追加・選択・削除・表示。
- スレッド全体の送信と、entryの作成要求の内容。
- スレッドの下書きの保存と復元。
- 投稿フォーム内の共有設定と投稿フォームの設定の配置。

### 2.2 対象外

- 既存の投稿へスレッドを継ぎ足す操作。
- 共有設定の保持と共有の処理そのもの。
- 画像・動画・リンクカードの各入力部品の内部の動作。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: 投稿フォームにセグメントを100件まで追加でき、1つのフォーム内に入力順に縦に並べる。
- FR-2: 2件目以降のセグメントも、先頭と同じ本文・画像・動画・リンクカード・返信と引用の設定・自己ラベル・言語を入力できる。
- FR-3: 任意のセグメントを選んで編集でき、編集中でないセグメントは内容を簡略化してグレーで表示する。
- FR-4: 編集中でないセグメントに画像があるときは、読み取り専用のサムネイルを表示する。
- FR-5: 先頭のセグメントは削除できず、2件目以降のセグメントはいつでも削除できる。
- FR-6: 各セグメントの左にアバターを表示し、後続のセグメントがあるときはアバターの間を縦線でつなぐ。
- FR-7: スレッド全体を1回のリクエストで送信し、送信中・成功・失敗の3状態だけを表示する。
- FR-8: 画像または動画を持つ先頭のセグメントの代表画像でentryの作成を要求し、該当するセグメントが無いか画像を自分で添付がONなら要求しない。
- FR-9: スレッド全体を1つの下書きとして、各セグメントの本文と自己ラベルを保存・復元し、画像と動画は下書きに含めない。
- FR-10: 他SNSへの共有は、先頭のセグメントの本文とentryのURLで1回だけ行う。
- FR-11: ポップアップを開く設定と画像を自分で添付は常に表示し、その他の共有設定と投稿フォームの設定は詳細オプションに置く。
- FR-12: 詳細オプションは、長文を省略して共有か投稿フォームを固定表示しないがONのときだけ、初期状態で開く。

## 5. 非機能要件

- NFR-1: 編集するセグメントの切り替えで、入力済みの本文と添付済みの画像の消失を0件にする。

## 6. 受け入れ条件

- AC-1 (FR-1): セグメントを追加すると末尾に1件増え、100件に達していると追加されない。
- AC-2 (FR-2): 2件目のセグメントに画像を添付して投稿すると、2件目の投稿に画像が含まれる。
- AC-3 (FR-3): 2件目を編集中にすると、1件目は簡略表示になり、1件目を選ぶと再び編集できる。
- AC-4 (FR-4): 画像を添付した1件目が編集中でなくなっても、サムネイルが表示される。
- AC-5 (FR-5): 先頭のセグメントには削除の操作が無く、2件目以降は削除できる。
- AC-6 (FR-6): セグメントが2件以上あるとき、1件目のアバターの下に縦線が表示される。
- AC-7 (FR-7): 2件のセグメントを投稿すると、2件の投稿を含む1回のリクエストが送信される。
- AC-8 (FR-8): 画像を持つセグメントが複数あると先頭の代表画像が送られ、0件か画像を自分で添付がONならentryを要求しない。
- AC-9 (FR-9): セグメントを下書きに変換して復元すると、本文と自己ラベルが保たれ、画像は空になる。
- AC-10 (FR-10): 2件のスレッドを投稿すると、共有文に先頭のセグメントの本文だけが含まれる。
- AC-11 (FR-11): 長文を省略して共有と返信・引用の設定を保存するトグルが、詳細オプションの中に表示される。
- AC-12 (FR-12): 自動ポップアップするSNSの値を変えても、詳細オプションが初期状態で閉じている。
- AC-13 (NFR-1): セグメントを追加して編集先を切り替えた後も、1件目の本文と画像のプレビューが残っている。
