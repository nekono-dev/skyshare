# スマホレイアウトのUI拡大 要件定義書

## 1. 背景・目的

スマホ幅（640px未満）で、フォント・ボタン・余白が全体的に小さく、読みにくく押しにくい。スマホ幅でのみ、各UIのフォントサイズ・余白・ボタンサイズを一回り大きくする。

## 2. スコープ

### 2.1 対象

- スマホ幅（`max-width: 639px`。FooterNav/Sidebarの切替境界と同じ）でのフォントサイズ・余白・ボタン寸法・アイコン寸法・FooterNavの高さ。
- トークン未使用（直書き）のフォントサイズ・余白のトークン化。

### 2.2 対象外

- 640px以上の見た目（直書きのトークン化に伴う微差を除き変更しない）。
- 色トークン、横幅（`--width-*` `--mobile-edge-margin`）、文中アイコン・ナビアイコン・FooterNavの寸法。

## 3. 機能要件

- FR-1: スマホ幅でフォントサイズ・余白・ボタン寸法の各トークンが一段大きな値になる。
- FR-2: トークンを参照するすべてのUIが、個別の編集なしに FR-1 の値へ追従する。
- FR-3: 直書きのフォントサイズ・余白はトークン参照へ置き換え、FR-1 の対象にする。
- FR-4: ボタンの操作領域は、スマホ幅で一辺44px以上を確保する。

## 4. 非機能要件

- NFR-1: スマホ幅で横スクロールが発生しない。FooterNavにより本文末尾が隠れない。
