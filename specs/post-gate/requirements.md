# 返信と引用の制限 要件定義書

## 1. 目的

投稿ごとに、返信できる相手と引用の可否を制限できるようにし、その既定値を端末に保存して、毎回の設定の手間を省けるようにする。

## 2. スコープ

### 2.1 対象

- 返信できる相手の制限と、引用の許可を、Blueskyのレコードへ変換すること。
- 返信と引用の設定を編集するダイアログ。
- 設定の既定値の保存と読み取り。

### 2.2 対象外

- 投稿に対するレコードの書き込み。
- 自分が所有するリストの取得。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: 誰でも返信できる設定のとき、返信の制限のレコードを作らない。
- FR-2: 返信不可の設定のとき、許可する相手が空の返信の制限のレコードを作る。
- FR-3: 相手を組み合わせる設定のとき、選んだメンション・フォロワー・フォロー中・リストごとの許可を、返信の制限のレコードに含める。
- FR-4: 返信を許可するルールの合計は5件までとし、超えるリストの許可は含めない。
- FR-5: 引用を許可するとき、引用の制限のレコードを作らず、許可しないとき、埋め込みを無効にする引用の制限のレコードを作る。
- FR-6: 返信と引用の既定値は端末に保存して読み取り、保存値が無いとき、壊れているとき、形式が不正なときは、初期の既定値を使う。
- FR-7: 設定が初期の既定値と一致するかを判定できる。
- FR-8: 投稿の後に既定値を更新するかどうかの設定を、端末に保存して読み取る。
- FR-9: 返信と引用のダイアログは、適用したときだけ編集した値を確定し、キャンセルしたときは値を変えない。

## 5. 非機能要件

- なし

## 6. 受け入れ条件

- AC-1 (FR-1): 誰でも返信できる設定のとき、返信の制限のレコードが作られない。
- AC-2 (FR-2): 返信不可の設定のとき、許可する相手が空のレコードが作られる。
- AC-3 (FR-3): 選んだ項目に応じた許可がレコードに含まれる。
- AC-4 (FR-4): 5件を超えるリストを指定すると、許可が5件に切り詰められる。
- AC-5 (FR-5): 引用を許可するとき、引用の制限のレコードが作られない。
- AC-6 (FR-5): 引用を許可しないとき、埋め込みを無効にするルールを含むレコードが作られる。
- AC-7 (FR-6): 既定値を書き込んで読み取ると、同じ値が得られる。
- AC-8 (FR-6): 保存値が無いとき、初期の既定値が返る。
- AC-9 (FR-6): 保存値が壊れているとき、初期の既定値が返る。
- AC-10 (FR-7): 初期の既定値と同じ設定を判定すると、一致すると判定される。
- AC-11 (FR-7): 返信できる相手が異なる設定を判定すると、一致しないと判定される。
- AC-12 (FR-9): ダイアログで返信不可を選んで適用すると、既定値として保存される。
- AC-13 (FR-9): ダイアログで値を変えてキャンセルすると、保存されない。
- AC-14 (FR-8): 投稿の後に既定値を更新する設定を書き込んで読み取ると、同じ値が得られる。
