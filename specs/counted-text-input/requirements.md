# 文字数カウンタ付きの入力欄 要件定義書

## 1. 目的

投稿の本文や見出しのように文字数に制約がある入力で、共有先ごとの数え方での文字数と上限を示し、入力欄の高さを内容に合わせて調整できるようにする。

## 2. スコープ

### 2.1 対象

- 文字数の数え方（書記素、Xの換算、タイッツーの換算）。
- 文字数カウンタを付けた入力欄の表示と、カウンタの状態の判定。
- 複数行の入力欄の高さの自動伸長。

### 2.2 対象外

- 共有文の組み立てと省略。
- 投稿本文の色付け。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: 書記素の文字数は、結合文字を含む絵文字を1文字として数える。
- FR-2: Xの換算の文字数は、全角を1、半角を2文字で1、URLを長さによらず固定の長さとして数える。
- FR-3: タイッツーの換算の文字数は、全角を1、半角を2文字で1とし、URLも全文字を数える。
- FR-4: 行の高さは、ピクセルで指定された値をそのまま使い、数値だけの指定は文字の大きさとの積にし、解決できない指定は文字の大きさの1.2倍にする。
- FR-5: 自動伸長の高さの範囲は、行数に行の高さを掛け、縦方向の余白を足して求め、最大行数を指定しないときは上限を設けない。
- FR-6: 内容の高さが最小の高さを下回るときは最小の高さに、最大の高さを超えるときは最大の高さに合わせ、最大の高さを超えるときだけ縦のスクロールを許す。
- FR-7: 利用できる高さから行数を逆算するときは、最小の行数と最大の行数の範囲に収める。
- FR-8: 入力欄は、複数行を指定すると複数行の欄に、指定しないと1行の欄になる。
- FR-9: カウンタは、件数・上限・ラベルを並べて表示する。
- FR-10: 各カウンタは、件数が誤りの閾値を超えると誤りの状態に、警告の閾値を超えると警告の状態になり、複数のカウンタがあるときは最も深刻な状態を全体の表示に使う。

## 5. 非機能要件

- なし

## 6. 受け入れ条件

- AC-1 (FR-1): 家族の絵文字が1文字として数えられる。
- AC-2 (FR-2): URLを含む文字列で、URLの長さを変えても換算の文字数が変わらない。
- AC-3 (FR-3): URLを含む文字列で、URLの全文字が数えられる。
- AC-4 (FR-4): 行の高さがピクセルで指定されたとき、その値がそのまま使われる。
- AC-5 (FR-5): 行数と最大行数から、最小の高さと最大の高さが求められる。
- AC-6 (FR-6): 内容の高さが最大の高さを超えるとき、高さが最大に切り詰められて縦のスクロールが許される。
- AC-7 (FR-7): 逆算した行数が最大の行数を超えるとき、最大の行数に収められる。
- AC-8 (FR-8): 複数行を指定するとテキストエリアが、指定しないと1行の入力欄が描画される。
- AC-9 (FR-9): カウンタが「件数/上限:ラベル」の形式で表示される。
- AC-10 (FR-10): 件数が誤りの閾値を超えると、誤りの状態になる。
- AC-11 (FR-10): 件数が警告の閾値を超え誤りの閾値以内のとき、警告の状態になる。
- AC-12 (FR-10): 複数のカウンタのうち1つが誤りの状態のとき、全体が誤りの状態になる。
