# 動画投稿 要件定義書

## 1. 背景・目的

Bluesky は投稿に動画（最大300MB）を添付できる。skyshare の投稿フォームは画像・OGPリンクのみに対応しており、動画を含む投稿を作成できない。また、動画付きの Bluesky 投稿は skyshare 上で表示も entry 化もできない。

本機能は、skyshare から Bluesky へ動画付き投稿を作成できるようにし、動画付き投稿を Timeline と Entry 詳細ページで扱えるようにする。

## 2. 用語定義

| 用語           | 意味                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------- |
| 動画           | `app.bsky.embed.video` として投稿に添付される動画。投稿に載る時点では常に mp4。                 |
| 動画投稿       | 動画を1本添付した Bluesky 投稿（segment）。                                                     |
| poster         | 動画の最初のフレーム相当の静止画（先頭付近の1フレーム）。サムネイル表示と visual の素材になる。 |
| 再生ボタン     | 動画であることを示す、中央に置く半透明の円形ボタン（X の動画の再生ボタンを模したもの）。        |
| 再生時間バッジ | 動画の長さを示す、左下に置く半透明の表示（X の動画の再生時間表示を模したもの）。                |
| 利用不可の動画 | 投稿に含まれているが、skyshare では再生・entry化できない動画（引用投稿に添付された動画等）。    |
| visual         | `dev.nekono.skyshare.defs#manifest` の `visual`。entry の代表画像（サムネイル）。               |
| 対応PDS        | 動画投稿が可能な PDS。Bluesky 公式ホスティング（bsky.social 系）に所属するアカウントのPDS。     |
| 投稿フォーム   | スレッド投稿を含む skyshare の投稿作成UI。                                                      |

## 3. スコープ

### 3.1 対象

- 投稿フォーム（単発投稿・スレッドの各segment）での動画の添付。
- 動画投稿の Bluesky への作成（スレッド内の任意の投稿を含む）。
- 動画投稿の entry の visual（サムネイル）の、投稿フォームでの配置・拡大率の調整。
- 動画投稿からの skyshare entry 作成（新規投稿時・既存の自分の動画投稿からの事後作成の両方）。
- Timeline 上での動画投稿のサムネイル表示。
- Entry 詳細ページでの動画の再生。
- skyshare 以外のクライアントで作成された動画投稿の、上記表示・entry 化。
- ゲストモード・サンプルページでの動画投稿の表示。
- 利用不可の動画を含む投稿の、利用できない旨の表示。

### 3.2 対象外

- 動画のキャプション（字幕 VTT）の添付・表示。
- GIF 表示ヒント（`presentation: gif`）の指定。
- 動画の編集・トリミング。
- skyshare 自身による動画の形式変換（mp4 以外の形式の変換は Bluesky の動画サービスが行う）。
- ブラウザが読み取れない動画（HEVC の mov を Chromium 系・Firefox で選択した場合等）の添付。
- 画像・OGPリンクと動画の同一投稿への併用。
- 1投稿への複数動画の添付。
- 利用不可の動画の再生・entry化（利用できない旨を表示するのみ）。
- 引用投稿（`recordWithMedia`）に添付された画像の扱いの変更（従来どおり）。
- 下書きへの動画の保存（従来どおり下書きはテキストのみを保持する）。
- 対応PDS以外（セルフホストPDS等）での動画投稿。
- 動画の日次アップロード残量の表示。
- ページのリロード・離脱をまたいだアップロードの再開。
- Timeline 上での動画の再生。

## 4. 機能要件

### FR-1: 動画の添付

- 投稿フォームの各segmentに、動画を1本添付できる。
- 動画の追加操作は、画像の追加ボタンに統合せず、画像の追加ボタンの隣に独立した動画専用のボタンとして提供する。ボタンの絵柄はビデオカメラを模したもので、色は他のUIのアイコンボタンと同じシステムの青色とする。
- 動画を添付したsegmentには、画像とOGPリンクを添付できない。画像またはOGPリンクを添付済みのsegmentには動画を添付できない。いずれの場合も、利用者が排他であることを認識できる。
- 添付した動画は、アップロード開始前に取り外せる。アップロード中・完了後にも取り外せる。取り外しは、画像の取り外しと同じ、プレビューのサムネイル右上の「×」ボタンで行う。
- 動画に代替テキスト（alt）を入力できる。入力は任意。入力は、画像の alt と同じく、プレビューのサムネイル右下の「alt」ボタンから開くダイアログで行う。
- 添付した動画は、画像と同じ見た目のサムネイル（1200×630 の領域に収めた、フォーム全幅の大きな表示）としてプレビューされる。このサムネイルは、entry の visual と同じ、再生ボタンと再生時間バッジ（FR-10）を重ねた画像で表示される。
- プレビューの「×」ボタンと「alt」ボタンは、画像・動画のどちらでも、ボタンであることが一目で分かるよう、十分な大きさ（タッチ操作しやすい寸法）で、縁取りつきで表示される。マウスオーバー時には色が変わる。
- 投稿フォームでスレッドの非アクティブなsegmentを縮小表示するときも、動画を添付したsegmentは、プレビューと同じ再生ボタン・再生時間バッジ入りの visual をサムネイルに用いる。

### FR-2: 動画の制約

- 添付できる動画は次の条件をすべて満たすもののみとする。
  - 形式が mp4・mov（QuickTime）・webm・mpeg のいずれかである。mp4 以外は、Bluesky の動画サービスによって mp4 に変換されたうえで投稿される。
  - 利用者のブラウザが動画の長さと縦横の寸法を読み取れる（再生可能である）。読み取れない動画は、形式が対応形式であっても添付されない。
  - サイズが 300,000,000 バイト以下である。
  - 長さが 10 分（600 秒）以下である。
  - 縦横比が Bluesky の許容範囲内である。
- 条件を満たさない動画は添付されず、違反の理由が利用者に通知される。
- 対応PDS以外のアカウントでは、動画を添付できず、その理由が通知される。

### FR-3: アップロードの進捗と失敗

- 動画の選択後、アップロードと変換の進捗が利用者に表示される。進捗は、プレビューのサムネイルの直下に表示される。
- アップロード・変換の中断（取り外し＝キャンセル）が可能である。
- 動画を添付したsegmentが1つでもある間は、その動画のアップロード・変換が完了するまで、投稿ボタンを押せない。動画を取り外す（キャンセルする）場合のみ、完了を待たずに投稿できる状態に戻る。
- アップロードが失敗した動画が残っている間も、投稿ボタンを押せない。取り外すか、別の動画を選び直す必要がある。
- 投稿ボタンが押せない理由が、利用者に表示される。表示位置は、入力欄の下の操作ボタン列（言語選択を含む）の直下で、動画のプレビューの上とする。
- Bluesky 側の制限（日次の上限、アップロード権限、混雑、変換失敗等）による失敗は、理由が区別できる形で通知される。失敗後は、同じsegmentで別の動画を選び直せる。

### FR-4: 動画投稿の作成

- 動画を添付した投稿を Bluesky に作成できる。動画の縦横比・altが保持される。
- スレッド内の複数のsegmentにそれぞれ1本ずつ動画を添付できる。
- skyshare の運用方針により、動画の実体は skyshare のサーバーを経由せずに Bluesky へ送られる。

### FR-5: entry の作成

- 動画投稿は、画像投稿と同じ条件で entry の作成対象になる（`manualImageAttach` が有効な場合は対象外とする既存方針を含む）。
- 動画投稿から作成する entry の visual は、poster から生成される（見た目は FR-10）。
- 自分の既存の動画投稿（skyshare 以外で作成したものを含む）から、事後に entry を作成できる。visual は動画の poster から生成される（見た目は FR-10）。
- 既存の動画投稿から entry を作成する際、動画の長さ（FR-10 の再生時間バッジに使う）を取得できなかった場合は、entry を作成せず、作成に失敗した旨を利用者に通知する。
- スレッドの中に動画投稿と画像投稿がある場合、entry の visual の素材にする投稿の選択は、既存の画像投稿の方針（スレッドのルートに最も近いメディア付き投稿）に従う。

### FR-6: Timeline での表示

- 動画投稿は、poster のサムネイルと、visual と同じ見た目の再生ボタンで表示される。
- Timeline 上では動画は再生されない。
- 動画投稿は entry 作成の対象として、画像投稿と同様に扱われる（作成対象外としてグレーアウトされない）。

### FR-7: Entry 詳細ページでの再生

- Entry 詳細ページでは、投稿の動画を再生できる。
- 初期表示では poster と、visual と同じ見た目の再生ボタンを表示し、利用者の操作（再生ボタン）で再生を開始する。ページを開いただけでは動画のデータを取得しない。
- 再生に失敗した場合は、元の Bluesky 投稿へ誘導する表示になる。
- 動画の縦横比に応じた表示領域が確保され、再生の前後でレイアウトがずれない。
- alt が設定されている場合、動画の代替テキストとして利用される。

### FR-8: 他クライアントの動画投稿・利用不可の動画

- skyshare 以外のクライアントで作成された動画投稿（動画が `app.bsky.embed.video` として直接添付されたもの）も、FR-5〜FR-7 と同様に扱われる。
- 利用不可の動画（引用投稿に添付された動画等）を含む投稿は、Timeline と Entry 詳細ページの両方で、動画が含まれているが skyshare では再生できないことが分かる表示になる。具体的には次を満たす。
  - 動画の poster が、暗く（再生できない状態を示す見た目で）表示される。
  - 「Skyshareでは再生できません」の旨の文言と、元の Bluesky 投稿へのリンクが poster に重ねて表示される。
  - 再生ボタンは表示されない。再生は開始できない。
- 利用不可の動画を含む投稿は entry 作成の対象外とする（動画も画像も持たない投稿と同じく、Timeline でグレーアウトされ、entry 作成ボタンは無効）。

### FR-9: ゲストモード

- ゲストモードの Timeline とサンプルEntryページに、動画投稿の例が表示される。
- サンプルEntryページでは、実際の Bluesky 上の動画に依存せずに動画の表示を確認できる。

### FR-10: 動画投稿の entry の visual の見た目

動画投稿から作成する entry の visual は、X の動画表示を模した次の見た目の1枚の画像とする。

- 画像全体に poster（最初のフレーム相当）を、既存の visual と同じ縦横比・領域で表示する。この画像全体が「動画の表示領域」であり、上記の中央・左下隅はこの画像に対する位置である。
- 動画の表示領域の中央に、再生ボタン（半透明の暗い円形に白い再生記号）を置く。動画の縦横比（横長・正方形・縦長）によらず、表示領域の中央に位置する。見た目は X の動画の再生ボタンに一致させる。
- 動画の表示領域の左下隅に、一定の余白を空けて、再生時間バッジ（半透明の暗い角丸の矩形に白い `m:ss` 形式の再生時間）を置く。見た目は X の動画の再生時間表示に一致させる。
- 色・透明度・寸法は、X の実際の表示から実測した値を設計で厳密に定める。

### FR-11: visual（サムネイル）の調整

- 動画を添付している間は、画像投稿と同じ「サムネ調整」ボタンが有効になり、entry の visual に使う poster の配置と拡大率を、画像投稿と同じ調整ダイアログで調整できる。アップロード中・完了後・失敗後のいずれでも調整できる（visual の調整は動画のアップロードと独立している）。
- 調整の結果は、投稿時に作成する entry の visual に反映される。再生ボタンと再生時間バッジは、調整後も FR-10 の位置・見た目で描かれる。
- 調整は entry の visual にのみ影響し、Bluesky に投稿する動画本体・Bluesky 上の poster には影響しない。
- 調整ダイアログでは、再生ボタンと再生時間バッジは表示しない（poster の配置だけを調整する）。確定後のプレビューのサムネイルは、調整後の配置の poster に再生ボタンと再生時間バッジを重ねた画像になる。調整によらず、再生ボタンは常に表示領域の中央に描かれる。

### FR-12: 「サムネ調整」ボタンの配置

- 「サムネ調整」ボタンは、画像追加ボタン・動画追加ボタンのどちらの操作とも独立した単一のボタンとして、動画追加ボタンの隣に置く。
- 画像または動画のいずれかを添付している間だけ表示される。どちらを添付していても、同じボタンから、添付しているメディアの調整ダイアログが開く（画像投稿では従来どおりの調整、動画投稿では FR-11 の調整）。
- 投稿処理中は操作できない。

## 5. 非機能要件

- NFR-1: 動画の実体（最大300MB）が skyshare のサーバー（Cloudflare Workers）を通過しない。
- NFR-2: skyshare が発行する動画アップロード用の認証情報は、用途が動画アップロードに限定され、有効期間が短い。認証情報はログに出力されない。
- NFR-3: 動画の再生機能は、再生を開始するまで画面の初期読み込み量を増やさない。
- NFR-4: 再生ボタンはキーボードで操作でき、操作対象の目的が支援技術に伝わる。
- NFR-5: 動画に関する利用者向けの文言は、既存のUIと同様に日本語・英語に対応する。
- NFR-6: 動画再生は、デスクトップ・モバイルの主要ブラウザ（Chromium系・Firefox・Safari）で動作する。
- NFR-7: 添付・アップロード・投稿のいずれの失敗でも、入力済みのテキスト・他の添付物は失われない。

## 6. 受け入れ条件

- AC-1: 301MBの動画、10分1秒の動画、対応形式（mp4・mov・webm・mpeg）以外のファイルを選択すると、添付されず理由が通知される。
- AC-2: 300MB以下かつ10分以下の mp4・mov・webm のいずれかを選択すると進捗が表示され、完了後に投稿できる。mov・webm の動画も、Bluesky 公式アプリで mp4 の動画と同じく動画として表示される（実アカウントでの手動確認）。
- AC-17: ブラウザが長さ・寸法を読み取れない動画（壊れたファイル、ブラウザが復号できないコーデックの動画）を選択すると、添付されず理由が通知される。
- AC-3: 動画を添付したsegmentで画像・OGPリンクが添付できず、画像添付済みのsegmentで動画が添付できない。
- AC-4: 動画付き投稿が Bluesky 公式アプリで動画として表示される（実アカウントでの手動確認）。
- AC-5: 動画投稿から作成した entry の visual が poster 由来の画像になる。
- AC-6: Timeline の動画投稿が poster サムネイルと再生マークで表示され、再生されない。
- AC-7: Entry 詳細ページで再生ボタンを操作すると動画が再生され、操作前は動画データが取得されない。
- AC-8: 対応PDS以外のアカウントでは動画を添付できず理由が通知される。
- AC-9: 動画の添付〜投稿で、動画のバイト列が skyshare サーバーへ送信されない（リクエストの検査で確認できる）。
- AC-10: 動画投稿から作成した entry の visual の中央（動画が横長・正方形・縦長のいずれでも同じ位置）に再生ボタン、左下に動画の長さを示す再生時間バッジが描画され、その色・透明度・寸法が設計で定めた値と一致する。
- AC-11: 利用不可の動画を含む投稿は、Timeline と Entry 詳細ページで poster が暗く表示され、再生できない旨と Bluesky へのリンクが表示され、再生ボタンが無く、Timeline では entry 作成ボタンが無効である。
- AC-12: 動画のアップロード・変換が完了していない間、または失敗した動画が残っている間は投稿ボタンが押せず、その動画を取り外すと（完了を待たずに）押せるようになる。
- AC-13: 既存の動画投稿から entry を作成する際に動画の長さを取得できない場合、entry は作成されず、失敗が通知される。
- AC-14: 動画の添付後、再生ボタンと再生時間バッジを重ねたサムネイルが画像添付時と同じ縦横比（1200:630）で大きく表示され、右上の「×」で取り外せ、右下の「alt」からダイアログで alt を入力できる。進捗はサムネイルの直下に表示され、投稿ボタンが押せない理由は操作ボタン列とプレビューの間に表示される。「×」「alt」ボタンは画像・動画とも大きく縁取りされ、マウスオーバーで色が変わる。非アクティブなsegmentの縮小表示のサムネイルも同じ visual になる。
- AC-15: 動画を添付すると「サムネ調整」ボタンが動画追加ボタンの隣に現れ、アップロード中でも押せる。ダイアログで配置・拡大率を変更して確定すると、プレビューのサムネイルが調整後の配置の poster に再生ボタンと再生時間バッジを重ねた画像になり、投稿時に作成される entry の visual がその配置の poster に再生ボタンと再生時間バッジを重ねた画像になる（再生ボタン・バッジの位置は調整前と同じ）。
- AC-16: 画像を添付した場合も同じ位置の同じボタンから、従来どおりの調整ができる。メディアを何も添付していない間はボタンが表示されない。
