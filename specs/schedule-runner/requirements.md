# 予約投稿の実行 要件定義書

## 1. 目的

実行時刻の到来した予約を、利用者のブラウザが閉じていても自動的に利用者の Bluesky へ投稿する。実行は利用料金の発生しない無料枠の実行制限の中で行い、制限で中断しても重複して投稿せずに続きから完了させる。

## 2. スコープ

### 2.1 対象

- 実行時刻が到来した予約の定期的な取り出しと実行。
- 画像・スレッド・返信と引用の制限・entry の作成。
- 失敗の分類と再試行、中断した実行の再開と回収。
- 終了した予約の履歴と不要な認証情報の削除。

### 2.2 対象外

- 予約の作成・取消を受ける API と画面。
- 動画を含む予約の実行。
- 投稿の失敗を利用者へ通知する仕組み。

## 3. 前提

- 前提: schedule-store — 予約・進捗・認証情報・画像の保管と取り出しを使う。

## 4. 機能要件

- FR-1: 1分ごとに、実行時刻が到来した待機中の予約を、実行時刻の早い順に5件まで取り出して実行する。
- FR-2: 予約ごとに予約用の認証情報でセッションを更新し、更新後のトークンを投稿より先に暗号化して保管する。
- FR-3: 画像のアップロード、投稿の先頭からの順次作成、投稿ごとの制限の作成、entry の作成の順に実行する。
- FR-4: 作成する投稿の日時は実行時の時刻とし、指定された既存の投稿があれば先頭の投稿をその返信にする。
- FR-5: 外部への通信の回数が上限に達したら、進捗を保ったまま予約を待機中へ戻し、残りを次の実行へ持ち越す。
- FR-6: 中断した予約は保持した進捗から再開し、作成済みの投稿を重複して作らない。
- FR-7: 一時的な失敗は最大5回まで再試行し、超えた予約は失敗として終了する。
- FR-8: 認証の失効・入力の不正・画像の欠落の恒久的な失敗は再試行せず、分類コードを記録して失敗とし、認証の失効では認証情報を削除する。
- FR-9: 成功した予約は投稿済みとして先頭の投稿の URI を記録し、保管した画像を削除する。
- FR-10: 実行中のまま10分以上更新されない予約を待機中に戻す。
- FR-11: 終了から7日が過ぎた予約と、予約がなく最後の使用から30日が過ぎた認証情報を削除する。
- FR-12: PDS がレート制限を返したら、その実行での以降の通信を止め、予約を待機中へ戻して次の実行へ持ち越す。

## 5. 非機能要件

- NFR-1: 実行時刻が到来した予約が5件以内のとき、実行時刻から3分以内に投稿の作成を開始する。
- NFR-2: 1回の実行で行う外部への通信を40回以内にする。
- NFR-3: 同じ予約から同じ位置の投稿を2件以上作成する件数を0件にする。
- NFR-4: 実行の経路で、atproto のライブラリを読み込む箇所を0件にする。
- NFR-5: パスワードとトークンを含む文字列を、ログと記録に出力する箇所を0件にする。

## 6. 受け入れ条件

- AC-1 (FR-1): 到来した予約が7件あるとき、1回の実行で早い5件が実行され、未到来の予約は実行されない。
- AC-2 (FR-2): 実行の開始時に更新されたトークンが保管され、その後の投稿の失敗でも保管したトークンが残る。
- AC-3 (FR-3): 画像つきの2件のスレッドと投稿の制限とentryの予約が、画像・投稿・制限・entryの順に作成される。
- AC-4 (FR-4): 作成された投稿の日時が実行時の時刻であり、返信先の指定があれば先頭の投稿がその返信になる。
- AC-5 (FR-5): 通信の上限に達した予約が進捗を保ったまま待機に戻り、次の実行で続きから完了する。
- AC-6 (FR-6): 2件目の作成の直後に中断した予約を再実行しても、1件目は再作成されず、同じ位置の投稿が1件ずつになる。
- AC-7 (FR-7): 一時的な失敗が5回続いた予約は失敗として終了し、4回目までは待機に戻る。
- AC-8 (FR-8): 認証が失効した予約は再試行されず、失敗と分類コードが記録され、そのアカウントの認証情報が削除される。
- AC-9 (FR-9): 成功した予約が投稿済みになり、先頭の投稿の URI が記録され、画像が削除される。
- AC-10 (FR-10): 10分以上更新のない実行中の予約が待機に戻り、直近に更新された予約は戻らない。
- AC-11 (FR-11): 終了から7日を超えた予約が削除され、予約がなく最後の使用から30日を超えた認証情報だけが削除される。
- AC-12 (FR-12): レート制限の応答を受けた実行が残りの通信を行わず、予約が待機に戻る。
- AC-13 (NFR-1): 実行時刻の直後の実行で、5件以内の予約が投稿の作成を開始する。
- AC-14 (NFR-2): 10枚の画像を持つ予約を5件実行しても、1回の実行での外部への通信が40回を超えない。
- AC-15 (NFR-3): 作成の直後に進捗の保存が失敗した予約を再実行しても、同じ位置の投稿が2件にならない。
- AC-16 (NFR-4): 実行の経路が、atproto のライブラリを読み込まない。
- AC-17 (NFR-5): 失敗した実行のログと記録に、トークンとパスワードの文字列が含まれない。
