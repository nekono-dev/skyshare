# 自分の画像blobの取得API 要件定義書

## 1. 目的

ブラウザから、自分が投稿した画像のblobを、CORSの制約を受けずに取得できるようにする。

## 2. スコープ

### 2.1 対象

- 自分のPDSからの画像blobの取得と、そのまま返す応答。

### 2.2 対象外

- 画像の加工と圧縮。
- 他人のリポジトリの画像の取得。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: ログインしていないとき、未認証として拒否する。
- FR-2: blobの識別子が指定されていないか空のとき、不正な依頼として拒否する。
- FR-3: 取得したblobは、元の内容種別を引き継いで返し、内容種別が無いときは汎用のバイナリ種別で返す。
- FR-4: blobが見つからないとき、失敗の原因に応じたステータスで応答する。

## 5. 非機能要件

- なし

## 6. 受け入れ条件

- AC-1 (FR-1): ログインしていないとき、401が返る。
- AC-2 (FR-2): blobの識別子が指定されていないとき、400が返る。
- AC-3 (FR-2): blobの識別子が空文字のとき、400が返る。
- AC-4 (FR-3): 取得元が内容種別を返すとき、その内容種別で画像が返る。
- AC-5 (FR-3): 取得元が内容種別を返さないとき、汎用のバイナリ種別で返る。
- AC-6 (FR-4): blobが見つからないとき、404が返る。
