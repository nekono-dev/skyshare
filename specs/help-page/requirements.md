# ヘルプページ 要件定義書

## 1. 目的

過去に寄せられた問い合わせと対処を、利用者が自分で確認できるようにする。

## 2. スコープ

### 2.1 対象

- 問い合わせと対処の記事の定義と、表示言語での組み立て。
- 記事を並べて表示するヘルプのページ。

### 2.2 対象外

- 問い合わせの受付。
- 記事の外部への配信。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: ヘルプの記事は、重複しない識別子と、空でない見出しと本文を持つ。
- FR-2: ヘルプの記事は、表示言語に合わせて組み立て、言語が変わっても記事の並びと識別子を変えない。
- FR-3: ヘルプのページは、記事を見出し付きのカードとして並べて表示する。

## 5. 非機能要件

- なし

## 6. 受け入れ条件

- AC-1 (FR-1): 記事の識別子が重複せず、見出しと本文が空でない。
- AC-2 (FR-2): 表示言語が変わると見出しの文言が変わり、記事の並びと識別子が変わらない。
- AC-3 (FR-3): ヘルプのページに、記事の見出しがカードごとに表示される。
