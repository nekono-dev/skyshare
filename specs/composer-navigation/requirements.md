# 投稿フォームの遷移の確認 要件定義書

## 1. 目的

投稿フォームで作成中の内容を、別のページへ移る操作で失わないようにし、予約投稿が無効のときは有効にする設定へ迷わず移れるようにする。

## 2. スコープ

### 2.1 対象

- 作成中に別のページへ移ろうとしたときの、下書き保存の確認。
- 予約投稿が無効のときにカレンダーのボタンを押したときの、設定への案内。

### 2.2 対象外

- 下書きの保存の API と、下書きの一覧の表示。
- ブラウザの戻る・進む、タブを閉じる、再読み込みでの確認。
- 設定のページでの予約投稿の有効化の操作。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: 未保存の本文があるときに別のページへ移ろうとすると、遷移を止めて、下書きを保存して移る・破棄して移る・編集を続けるの3択を出す。
- FR-2: 本文が空のときと、開いた下書きから変更がないときは、確認を出さずにそのまま移る。
- FR-3: 予約投稿が無効のときにカレンダーのボタンを押すと、設定で有効にする案内を出し、設定を開くを選ぶと設定のページへ移る。

## 5. 非機能要件

- NFR-1: 保存の確認を出す前に、遷移先のページを表示する回数を0にする。

## 6. 受け入れ条件

- AC-1 (FR-1): 本文を入力してフッターの設定を押すと3択の確認が出て、下書きを保存を選ぶと下書きの保存が1回呼ばれて設定のページへ移る。
- AC-2 (FR-1): 破棄を選ぶと保存を呼ばずに設定のページへ移り、編集を続けるを選ぶと移らず本文が残る。
- AC-3 (FR-2): 本文が空のときにフッターの設定を押すと、確認が出ずに設定のページへ移る。
- AC-4 (FR-3): 予約投稿が無効のときにカレンダーのボタンを押すと案内が出て、設定を開くを選ぶと設定のページへ移る。
- AC-5 (FR-3): 本文があるときに案内の設定を開くを選ぶと、移る前に3択の確認が出る。
- AC-6 (NFR-1): 3択の確認が出ている間、表示中のページの住所が変わらない。
