# 投稿言語の選択欄 要件定義書

## 1. 目的

約180件ある投稿言語から目的の言語を素早く見つけられるよう、国旗付きで絞り込める選択欄を提供する。

## 2. スコープ

### 2.1 対象

- 投稿言語の選択欄の選択肢と絞り込みの対象。
- 言語ごとの国旗の表示。

### 2.2 対象外

- 国旗画像の導入。国旗は絵文字とし、国旗の絵文字を描画できない環境で2文字の国コード表記になることを許容する。
- 表示言語の選択。

## 3. 前提

- なし

## 4. 機能要件

- FR-1: 投稿言語の選択欄は検索付きのプルダウンとし、言語名と言語コードのどちらでも絞り込める。
- FR-2: 各言語の選択肢には、その言語を代表する国の国旗を言語名の前に表示する。
- FR-3: 複数の国にまたがる言語は、代表国を1つに固定して国旗を表示する。
- FR-4: 人工言語・古典言語・国に対応づけられない言語は国旗を表示せず、一覧でのラベルの開始位置を他の言語と揃える。
- FR-5: トリガーの現在値にも国旗を表示し、国旗の無い言語ではトリガーに国旗を表示しない。

## 5. 非機能要件

- なし

## 6. 受け入れ条件

- AC-1 (FR-1): 言語コードの「ko」を入力すると、韓国語に絞り込まれる。
- AC-2 (FR-2): 日本語の選択肢に日本の国旗が表示される。
- AC-3 (FR-3): 複数の国で使われる英語に、代表国である米国の国旗が対応する。
- AC-4 (FR-4): エスペラント語に国旗が無く、一覧でラベルの左端が国旗付きの言語と揃う。
- AC-5 (FR-5): 韓国語を確定するとトリガーに国旗と言語名が表示され、国旗の無い言語ではトリガーに国旗が表示されない。
