# 再採用する機能の資料

`dev/survey` の実装時の要件・設計・検証記録を、機能の参照資料として保存する。cc-sdd の設定・フック・指示ファイルは導入しない。

- `survey-definition`: アンケート設定の検証と配信用ファイルの生成。
- `survey-api`: 匿名回答、回答済みの記録、保持期限による削除。
- `choice-question`: 単一選択・複数選択の共通部品。
- `survey-form`: 起動時の判定と回答ダイアログ。
- `survey-operation`: 手元の CLI と運用スキル。

これらは実装時の資料であり、従来の `specs/` 形式への再編は未実施。従来からある仕様と検査は `specs/` に保持し、DB 改名とプライバシーポリシーの変更を反映している。新機能のテスト名の数値タグは、この資料の要件番号に対応する。

運用時の手順は `DEVELOP.md` を参照する。cc-sdd を使った試行の全履歴は `dev/codex-cc-sdd` に保存している。
